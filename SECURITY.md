# Security

Kith is software for children, run by families on their own servers. If you find a security or child-safety problem,
please report it privately rather than in a public issue:

- Use GitHub's **private vulnerability reporting** on this repository (Security › Report a vulnerability).

Please include what you found, how to reproduce it, and what you think the impact is. You'll get a reply as soon as
possible, and a fix will be released before details are made public.

Things that are especially important to us:

- anything that gets past the safety check, the safeguards, or the reporting to the parent;
- anything that lets the companion, the desk or its browser reach something it shouldn't (the home network, sign-ins,
  downloads, sites on the block list);
- anything that exposes a child's chats, memories or personal details to someone else;
- sign-in and session problems.

## Supported versions

Kith is early software. Only the latest version on `main` gets fixes.
