Set up Kith

A friendly walk-through, from an empty server to your child's first chat. Setup takes an afternoon, about three hours with breaks. For every detail, the full setup guide on GitHub has it.

You're the operator. If you set up Kith, you run it: its server, security and backups, your Claude account and costs, the children who use it and their parents' consent, and data protection for your family. See the terms.

What you'll need

  • An always-on computer that runs Docker (an old Mac mini is fine)
  • An Anthropic account under the Commercial Terms, with a monthly limit
  • A sign-in provider such as Pocket ID
  • A web address with https, through a reverse proxy
  • Comfort with a terminal: you'll copy and paste a few commands

1Step 1 of 11 · about 15 minutes

A home server with Docker

Kith runs on any computer that's always on and can run Docker: an old Mac mini, a small Linux box, a NAS that runs containers. In its light mode (the default) it needs about 1 GB of memory, a little more during calls.

Install Docker (Docker Desktop on a Mac, Docker Engine on Linux), then check it works:

docker --version
docker compose version

Good to know

You'll also want git, to download Kith and update it later. On a Mac it comes with the Xcode command line tools (xcode-select --install).

2Step 2 of 11 · about 5 minutes

Get Kith

Download Kith into a folder on the server. Everything else in this guide happens in that folder.

git clone https://github.com/DemiInfinity/kith.git
cd kith

Your settings will live in a file called .env in this folder. Nothing family-specific lives in the code.

3Step 3 of 11 · about 15 minutes

Your Claude key and a spending limit

Kith thinks with Claude, through Anthropic's API, using a key that only ever lives on your server.

  1. In the Anthropic Console, use an organisation under Anthropic's Commercial Terms (Settings › Organization shows which). The Consumer Terms don't allow under-18s.
  2. Make a workspace just for Kith, so its spending and keys stay separate.
  3. Set that workspace's monthly spend limit (Settings › Limits). This is the cap that really protects you; $50 a month is a good start.
  4. Create an API key in that workspace. You'll paste it in step 5, or later in Kith Parent (Settings › Claude), where it's checked and stored encrypted.

Good to know

Kith adds its own limits on top: a weekly allowance, Full power per few hours, a smooth switch to Low power, and a hard stop for the month ($48 by default, under a $50 cap). Everyday use costs about a penny a chat turn, and $1.50 to $2 for a 30-minute call.

4Step 4 of 11 · about 20 minutes

Sign-in with Pocket ID

Only your family gets in, through your own sign-in service. Kith works with any OpenID Connect provider; Pocket ID is the easiest, with passkeys instead of passwords.

  1. In Pocket ID, add an OIDC client called “Kith”, as a public client (PKCE, no secret).
  2. Callback URL: https://your-kith-address/auth/callback. Logout callback URL: https://your-kith-address/.
  3. Create two groups, kith-child and kith-parent, and put your child in the first and yourself in the second.
  4. Note the client ID: the next step asks for it.

Good to know

Groups are the simplest way to say who gets in. You can also list user IDs or verified emails instead (see the full guide). Anyone not in a group or list can't sign in at all.

5Step 5 of 11 · about 10 minutes

Run the setup script

One script fills in .env for you. It makes the secrets Kith needs itself, asks for your address, sign-in details and Claude key, and checks the key with Anthropic. What you type for secrets is hidden, and nothing is ever printed.

./scripts/setup-secrets.sh

Press Enter to keep anything already set. To see what's set without changing anything:

./scripts/setup-secrets.sh --check

Good to know

.env holds your secrets, and only you can read it. Keep a private copy with your backups. Never change KITH_SECRET_KEY once it's set: the saved Claude key and Google tokens are encrypted with it.

6Step 6 of 11 · about 10 minutes

Start it

Build and start Kith. The voice profile adds the two small voice containers for calls; leave it out if you don't want calls.

docker compose --profile voice up -d --build
docker compose logs -f kith

When the log settles, docker compose ps shows each service as healthy. Kith listens on port 8787.

Good to know

The first start downloads the voice models, which takes a few minutes. After that, speech never leaves the house and recordings aren't kept.

7Step 7 of 11 · about 20 minutes

A web address with https

Phones need a proper https address to use the microphone and notifications. Put Kith behind your reverse proxy (Nginx Proxy Manager, Caddy, Traefik…):

  • Proxy your address (for example kith.example.com) to the server's port 8787.
  • Turn on WebSocket support. Calls and live updates need it (in Nginx Proxy Manager it's “Websockets support”).
  • Set KITH_PUBLIC_URL in .env to the https address. If the proxy is on another machine, also set KITH_BIND=0.0.0.0.
docker compose --profile voice up -d

8Step 8 of 11 · about 10 minutes

Install it on phones and Macs

  • iPhone and iPad: open your Kith address in Safari, then Share › Add to Home Screen. Open it from the Home Screen to sign in and turn on notifications.
  • Mac: download Kith and Kith Parent, drag them to Applications, and use Kith › Change Server… to type your address. They aren't signed yet, so the first time, open the app, then choose Open Anyway in System Settings › Privacy & Security.
  • Anything else: just open the address in a browser, on Windows, Android or a Chromebook.

Good to know

Signing in from an installed app happens in the browser, where passkeys work. The app shows a 4-digit code: check the browser shows the same one, then tap Yes.

9Step 9 of 11 · about as long as you like

Optional extras

  • Voice: Kith Parent › Settings › Voice picks the listening model and voices, and can use a Wyoming server you already run (like Home Assistant's).
  • Google: saving to a Kith folder in your child's Drive, and optionally Docs, Calendar and Tasks, each off until you switch it on. The easiest way is a shared Kith Connect helper (one setting, no Google Cloud setup); or make your own Google client in about 15 minutes. See docs/google.md.
  • Reports to Home Assistant: send reports to a family board or your phone through a Home Assistant script. The setup script asks; Kith Parent's “Send a test report” checks it works.
  • Connections: bedroom lights, Kin, Jellyfin, MCP servers and more, each one look-only or allowed to act, all off until you add them in Kith Parent › Connectors.

10Step 10 of 11 · about 15 minutes

Backups and upgrades

Everything lives in two Docker volumes, kith-data and desk-data, plus your .env. Kith can keep running while you back up. A safe copy of the database:

docker compose exec kith node --disable-warning=ExperimentalWarning -e "new (require('node:sqlite').DatabaseSync)('/data/kith.sqlite').exec(\"VACUUM INTO '/data/backup.sqlite'\")"
docker compose cp kith:/data/backup.sqlite ./kith-$(date +%F).sqlite
docker compose exec kith rm /data/backup.sqlite

Then the chat archive and the desk's files:

docker run --rm -v kith_kith-data:/v:ro -v "$PWD":/backup alpine tar czf /backup/kith-history-$(date +%F).tgz -C /v history
docker run --rm -v kith_desk-data:/v:ro -v "$PWD":/backup alpine tar czf /backup/desk-data-$(date +%F).tgz -C /v .

To upgrade: back up first, get the new version, then rebuild. The database updates itself safely on start.

git pull
docker compose --profile voice up -d --build

Good to know

Backups hold chats, memories and reports, so keep them private and off the server, and delete old ones on the same schedule as chats (30 days by default). Restoring is in the full guide.

11Step 11 of 11 · about a few minutes

Light and full mode, and moving machines

Kith starts in light mode, comfortable on an old Mac mini with 8 GB of memory. On a bigger machine, raise the memory limits and use a more accurate listening model in .env (the full guide has the table), then restart without rebuilding:

docker compose --profile voice up -d

Moving to another machine: stop Kith, copy the two volumes and .env across, restore them, and start it. Keep KITH_SECRET_KEY exactly the same. The full guide has the commands.

If something's not right

Sign-in says “That account isn't set up for Kith”.

The person isn't in the kith-child or kith-parent group in Pocket ID (or the ID and email lists). Add them, then try again.

Calls don't work, or the microphone isn't allowed.

Microphones need https, so use your https address, not the server's IP. Check WebSocket support is on in your proxy, and that the voice containers are running (Kith Parent › Settings › Voice › Check the voice servers).

The companion says it isn't switched on yet.

There's no Claude key yet. Paste one in Kith Parent › Settings › Claude, or run the setup script again.

Notifications don't arrive on an iPhone.

On iPhone they only work from the Home Screen app: Share › Add to Home Screen, open it from there, then turn notifications on.

The Mac app says it can't be opened.

The apps aren't signed yet. Open it once, then choose Open Anyway in System Settings › Privacy & Security.

Something else went wrong.

Run docker compose logs kith and look at the last lines, and ./scripts/setup-secrets.sh --check to see what's missing. Still stuck? Open an issue on GitHub (without any secrets in it).
